# 할 일 관리 앱 PRD

## 1. Why - 목적
- 일일 할 일을 주간 계획과 1년 목표에 연결해 실행과 목표를 하나의 구조로 관리
- 할 일 상태(todo/doing/done)를 보드에서 바로 바꿀 수 있게 함
- 주간 진행률을 자동으로 계산해 수작업 집계를 없앰

## 2. Who - 타깃 사용자
- 장기 목표를 일 단위 실행으로 나눠 관리하려는 개인 사용자
- 주간 단위로 계획을 세우고 회고하는 사용자
- 칸반 보드 방식의 상태 관리에 익숙한 사용자

## 3. User Flow
1. 1년 목표 생성
2. 주간 계획 생성 → 1년 목표에 연결
3. 할 일 생성 → 주간 계획에 연결 (기본 상태: todo)
4. 일일 보드에서 할 일 확인 (todo / doing / done 컬럼)
5. 드래그 앤 드롭으로 상태 변경
6. 상태 변경 즉시 주간 진행률 자동 갱신
7. 주간 화면에서 진행률 확인 → 1년 목표 화면에서 연결된 주간 계획 확인

## 4. 기능 요구 사항

### P0 - 핵심 기능

**할 일 CRUD**
- 생성: 제목(필수), 날짜(필수), 연결할 주간 계획(선택)
- 조회: 날짜별 목록 / 상태별 보드
- 수정: 제목, 날짜, 상태, 연결된 주간 계획
- 삭제: 삭제 전 확인 → 삭제 후 주간 진행률 재계산

**상태 관리**
- 상태값: `todo` / `doing` / `done`
- 생성 시 기본값: `todo`
- 상태 변경 시 변경 시각 기록

**드래그 앤 드롭 상태 변경**
- 보드 컬럼: todo / doing / done
- 카드를 다른 컬럼으로 옮기면 상태가 바뀜
- 드롭 즉시 저장, 실패하면 원래 위치로 되돌림
- 같은 컬럼 안에서는 순서만 변경

**기간 구조**
- 일일: 특정 날짜의 할 일
- 주간: 주 시작일·종료일, 주간 계획 목록
- 1년 목표: 연도, 목표 제목

**구조 연결**
- 연결 관계: 할 일(N) → 주간 계획(1) → 1년 목표(1)
- 연결 해제·변경 가능
- 상위 항목 삭제 시 하위 항목은 연결만 해제 (데이터 유지)

**주간 진행률 자동 반영**
- 계산식: `done 할 일 수 ÷ 연결된 전체 할 일 수 × 100`
- 할 일을 생성·수정·삭제하거나 상태를 바꿀 때 자동 재계산
- 연결된 할 일이 0개이면 0% 표시

**데이터 모델**
- `YearGoal`: id, year, title
- `WeeklyPlan`: id, year_goal_id, week_start, week_end, title, progress
- `Task`: id, weekly_plan_id, date, title, status, order, updated_at

### P1 - 추가 기능
- 1년 목표 진행률: 연결된 주간 계획들의 진행률을 집계
- 상태 필터, 날짜 이동(이전/다음 날·주)
- 마감되지 않은 할 일을 다음 날이나 다음 주로 이월
- 주간 회고 메모
- 모바일에서 드래그 앤 드롭 대신 터치로 상태 변경
